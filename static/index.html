Cookie osu!

JSON из Cookie Editor, Netscape cookies.txt или строка Cookie. Только для osu.ppy.sh. Хранятся в памяти локального сервера до 8 часов, на диск не записываются.

Экспортируйте все cookie со страницы osu.ppy.sh, включая HttpOnly osu_session. Успешный импорт формата еще не подтверждает вход на сайте.

Официальный API osu!

OAuth Client Credentials читает публичные результаты без cookie и входа игрока. Нужны ключи приложения API v2.

  1. Войдите на osu! и откройте настройки OAuth-приложений.
  2. Нажмите "New OAuth Application". Назовите приложение, например pulse personal.
  3. Для Client Credentials поле Application Callback URL можно оставить пустым.
  4. Скопируйте Client ID и Client Secret одного приложения в поля ниже. Старый API key не подходит.

Ключи и токен хранятся только в памяти локального сервера до 8 часов. Перезапуск удаляет сессию. Это не дает доступа к полному архиву игр.

На веб-демо по HTTP ввод ключей отключен. Откройте локальную версию на http://127.0.0.1:8000. Владелец сервера также может настроить API через .env.

Документация osu! API

HP по NF-реплею

Официальный движок osu! воспроизводит курсор и нажатия, считает попадания, тики, промахи и HP. Исходная игра и файлы клиента не меняются. Расчет может занять до 3 минут, повторный берется из кеша.

Для файла нужна точная карта в каталоге. Подходят stable и lazer, только osu!standard. Результат расчета не превращается в новую сыгранную попытку без NF.

CNN: паттерны карты

Модель читает последовательность нот и форму слайдеров. Обучение сравнивает оригинал, отражения X, Y, XY и все четыре варианта вместе. Результаты попыток сохраняются. Проверка идет на исходных картах из других семейств песен.

Обучение запускается отдельно и может занять несколько минут. Каждый выход подключается к прогнозу только после улучшения на проверке. Для accuracy используются полные проходы; NF и best в этот эксперимент не входят.

Ошибки по участкам

Отдельная модель учится на событиях локальных реплеев stable и lazer: промахах, срывах комбо и попаданиях ниже 300. Она не определяет причину ошибки. Реплеи с несовпавшей статистикой исключаются. В этом наборе только законченные карты.

Разбор реплеев идет без звука, по одному процессу. Перед запуском проверяется отключение звука. Первый сбор может занять десятки минут, повторный использует кеш.

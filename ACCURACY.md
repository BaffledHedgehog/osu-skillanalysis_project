# Улучшение прогноза accuracy

Личный эксперимент BaffledHedgehog от 05.11.2026: для NM MAE снизилась с 4.67 до 4.35 п.п. на 403 более поздних играх из 239 семейств карт. На всех модах: 4.89 против 4.31 п.п., 433 игры, 254 семейства. Отдельная проверка других модов пока мала, поэтому подключен только NM.

## Изменения

- Запасной расчет берет accuracy полных успешных попыток. Незавершенные провалы не занижают точность предполагаемого прохождения.
- Если полных результатов нет, приложение сообщает об отсутствии данных для accuracy.
- Best описывают показанные навыки, но не входят в наблюдаемую долю успешных обычных попыток.
- Новая модель использует 56 признаков: нагрузку карты, моды, прошлые проходы, похожие карты, относительную сложность и давность.
- Для личного профиля выбран HistGradientBoostingRegressor с `loss="absolute_error"`. Оценка соответствует задаче уменьшения MAE и менее чувствительна к редким большим ошибкам, чем среднеквадратичная потеря Ridge.

История разделена по времени: модель обучалась до 30.09.2026, поздние игры проверяли прогноз. Семейства проверочных целевых карт удалены из обучающих целевых примеров. Вариант выбирался внутри ранней части по GroupKFold, без поздних результатов. Профиль в каждой попытке строился только по более ранним завершенным играм других семейств. Во время поздней проверки профиль мог обновляться после уже завершенных игр, веса модели не менялись.

Для оценки каждой песни задан одинаковый вес. Повторы одной карты не должны определять результат всей проверки. Для NM 95% интервал разницы ошибки нового варианта и Ridge по повторным выборкам семейств: от -0.616 до -0.043 п.п. Это результат на сохраненной истории одного игрока; новые живые прогнозы требуют отдельной проверки.

## Где лежит эксперимент

`.data/accuracy-improvement/` содержит:

- `historical.db`: исходный общий набор до повторного сетевого сбора.
- `plan.json`, `selected-before-test.json`: план общего эксперимента и выбор модели до раскрытия свежих accuracy.
- `global-report.json`: результат общей модели. Она не подключена: свежая проверка содержит только пять пригодных проходов одного тестового игрока и не улучшает простое среднее.
- `personal-history.db`, `personal-plan.json`: снимок личной истории и протокол проверки.
- `personal-selected-before-test.json`: выбор по ранним играм.
- `personal-benchmark-model.json`, `personal-benchmark-inputs.npz`: замороженные модели и входы проверки.
- `personal-test-predictions.json`: прогнозы, базовый Ridge и даты игр контекста.
- `benchmark-reproduction.json`: точное воспроизведение и проверка причинности истории.
- `personal-model.json`: итоговые веса, переобученные на доступной истории после завершения проверки.

Исходный `.data/population` не перезаписывается новым экспериментом. В git не попадают ни базы, ни снимки, ни веса.

## Использование в приложении

Проверенные веса лежат в `models/*-accuracy-v2.json` рядом с рабочей базой. Сайт читает их без обучения. Модель применяется только к своему игроку, разрешенным модам и диапазону звезд. Остальные случаи обслуживает прежний расчет. JSON-прогноз проверен на совпадение со sklearn, pickle не используется.

Веса установлены для тестового стенда и обычной базы `.data/osu_skill.db`. При переносе между этими базами сохранена исходная база обучения и проверено совпадение не менее 200 score_id и 80% меньшей истории игрока.

Для нового личного эксперимента выберите отдельную папку:

```powershell
python -m app.accuracy_lab --personal-only --personal-db .data/osu_skill.db --personal-user BaffledHedgehog --folder .data/accuracy-new-run --publish-personal
```

Для обучения требуется минимум 400 пригодных обычных проходов. Команда публикует веса только при выполнении проверки. Существующая папка эксперимента использует свой замороженный снимок для воспроизводимости; для обновленного набора нужна новая папка.

Пересобрать отчет текущего эксперимента:

```powershell
python deliverables/build_accuracy_report.py
```

Методы: [бустинг и абсолютная ошибка](https://scikit-learn.org/1.8/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html), [разделение по группам](https://scikit-learn.org/1.8/modules/generated/sklearn.model_selection.GroupKFold.html).

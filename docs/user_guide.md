# Как пользоваться pulse!

Для: игрока osu!standard. Владелец: Темиров А.М. Актуально: 07.11.2026.

Приложение помогает сравнить карту со своими результатами и заранее увидеть сложные участки. Полный профиль всех 16 навыков пока не готов.

1. Открыть локальный сайт.
2. Вставить ссылку на свой профиль или ник и нажать "Собрать данные".
3. Дождаться отчета сбора. Недоступный список не считается пустой историей всех игр.
4. Добавить карту по ссылке, ID, .osu или .osz.
5. Выбрать моды, с которыми планируется игра.
6. Посмотреть свой ориентир и нагрузку карты по aim/speed, число проходов и разных карт, затем прогноз, его источник и график нагрузки. При желании открыть "Что сыграть дальше".

Шанс прохождения относится к попытке в выбранных условиях, а не обещает проход. 80% допускает провалы. Accuracy - ожидаемая точность при прохождении; интервал не гарантирует попадания результата внутрь. Текущие проценты сами по себе не доказывают качество модели.

Aim описывает наведение, speed - нагрузку на нажатия. Личный ориентир считается по разным полностью пройденным картам с теми же модами и учетом давности. Выбранная карта исключена из его расчета. Показываются ориентир, нагрузка выбранной карты и разница в процентах. Для оценки нужны хотя бы три разные подходящие карты. При нехватке данных цифра не выдумывается. Если обычных проходов мало, лучшие достижения могут дополнить ориентир; это подписано. Это описательная оценка, не отдельная нейросеть навыка и не жесткое ограничение вероятности.

График показывает нагрузку карты, а не доказанную причину личной ошибки. Дополнительно учитываются AR, ритм, слайдеры, моды и пики. Отдельного проверенного измерителя всех 16 групп еще нет.

Старые игры имеют меньший вес. Best отражают лучшие достижения, а не полную историю попыток. NF не считается проходом без NF. Уже известные сыгранные и добавленные карты исключаются из подбора, но неполная история может оставить неизвестные приложению повторы.

Если исходных данных мало, лучше импортировать свою локальную историю. Расширенные настройки предназначены для владельца локальной установки. Не вставлять cookie и ключи в чат или публичные документы. Базовый сценарий работает без них.

Если файл не принят, проверить, что это карта standard .osu/.osz.

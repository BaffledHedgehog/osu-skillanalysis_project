# Пакет документов pulse!

Версия 0.2 от 17.10.2026. Основа: проект 2 из таблицы команд, README.md, PROJECT_PLAN.md и лекция 3 в lectures/.

## Что сдавать

1. Паспорт проекта - pulse!.docx
2. Реестр требований - pulse!.docx
3. RACI - pulse!.xlsx
4. Календарный план - pulse!.pod для ProjectLibre
5. Календарный план - pulse!.xlsx для просмотра; XML оставлен как обменный формат
6. Техническое задание - pulse!.docx
7. Границы WBS и решения - pulse!.docx: Scope / Out of Scope, WBS и Decision Log

Календарный план содержит 20 работ, 5 вех, 34 связи, критический путь и резерв 3 рабочих дня. Старт 19.10.2026, расчетное завершение 21.12.2026. Дата сдачи пока не объявлена. План считает рабочими понедельник-пятницу и не учитывает государственные праздники. После объявления даты сдачи нужно пересчитать план и проверить загрузку команды.

Роли трех участников, кроме Team Lead, распределены предварительно по просьбе инициатора. Это помечено в документах.

Файл .pod создан установленным ProjectLibre 1.9.8 из XML и открыт повторно. Проверка подтвердила 25 записей, включая 5 вех, 34 связи и RACI у каждой записи. Для сдачи открывайте .pod напрямую в ProjectLibre.

RACI хранится внутри .pod в текстовых полях задач: Text1 = R, Text2 = A, Text3 = C, Text4 = I. Те же роли расписаны в заметках каждой задачи. Чтобы увидеть матрицу рядом с календарным планом, в таблице Ганта нажмите правой кнопкой на заголовке столбца и добавьте столбцы Text1, Text2, Text3, Text4. Коды WBS связывают задачи с отдельной таблицей RACI.

Документы, таблицы и XML создаются повторно командой `python deliverables/build_course_pack.py`. Для запуска нужны `python-docx` и `xlsxwriter`. После изменения XML файл .pod нужно пересоздать через `ConvertProjectLibre.java` с Java 21 и библиотекой установленного ProjectLibre. Обычный импорт XML в ProjectLibre 1.9.8 не переносит поля Text1-Text4, поэтому конвертер заполняет их после импорта и проверяет готовый .pod.

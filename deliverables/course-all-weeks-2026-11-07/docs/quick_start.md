# Быстрый запуск pulse!

Для: нового участника и проверяющего. Владелец: Гайфуллин А.Р. Актуально: 07.11.2026.

Нужен Python 3.11 или новее. Команды PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000. Ввести BaffledHedgehog или публичную ссылку на игрока, нажать "Собрать данные". Добавить карту по ID 4610937 или загрузить свой .osu/.osz. Открыть анализ. Для первого результата новые игры после запуска не нужны.

Ожидается: название карты, звезды, aim, speed, график нагрузки, доступные оценки игрока и источник прогноза. При нехватке истории прогноз может отсутствовать. Сбор из сети зависит от источника; пароль игрока не нужен. Для импорта lazer отдельно нужен .NET SDK; для базового сетевого сценария он не требуется.

Проверка запуска: http://127.0.0.1:8000/api/health должен вернуть HTTP 200. Для проверки импорта без сети загрузить `deliverables/test-kit/inputs/valid-map.osu`, если файл есть в текущем комплекте. Список точных имен входных файлов: `deliverables/test-kit/inputs/`.

На компьютере автора подготовлен отдельный стенд: http://127.0.0.1:8011/?user=BaffledHedgehog&map=4610937. На другом компьютере базы и личной модели из него не будет. Они не входят в git. Для переноса личной истории нужно отдельное согласованное действие владельца; обычный запуск создает свою базу.

07.11 автоматически проверена новая копия исходников без личных баз: создано отдельное venv, установлены requirements.txt, запущен сервер, загружены четыре контрольные карты и проверен отчет навыков. Это проверка чистой установки на компьютере автора; отдельный человек на другом ПК после обновления еще не повторял всю инструкцию. Скриншоты ручного прогона коллег подтверждают запуск их копии.
